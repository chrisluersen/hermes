Privacy Policy

Hermes — last updated 2026-10-12

Hermes is a personal, single-user automation assistant that runs locally on the owner's own computer. This policy describes how Hermes accesses, uses, stores, and shares Google user data. Hermes is used only by its owner, on the owner's own Google Account.

What data Hermes accesses

With the owner's authorization, Hermes accesses the following Google data, and only for the owner's own account:

  • Gmail — read messages, send messages, and read Gmail settings (filters and labels).
  • Google Calendar — read and create calendar events.
  • Google Drive — read, upload, and organize files.
  • Google Docs — read and edit documents.
  • Google Sheets — read and edit spreadsheets.
  • Google Contacts — read contact names and details.
  • Google Tasks — read and manage tasks.
  • YouTube — read subscription information.

How the data is used

Google user data is used solely to perform actions the owner requests through Hermes — for example, summarizing email, creating a calendar event, or updating a spreadsheet. Data is never used for advertising, profiling, or any purpose other than carrying out the owner's own instructions.

How the data is stored

Hermes runs locally on the owner's own computer. Google user data retrieved by Hermes is stored only on that computer, in the owner's local files and databases. OAuth credentials are stored locally on the same computer and are used only to authenticate to Google on the owner's behalf.

How the data is shared

Google user data is not shared, sold, rented, or transferred to any third party. Hermes does not transmit Google user data to any external service, and no other person or system has access to it. Google user data is not used to train or improve any machine-learning or artificial-intelligence model.

Retention and deletion

Data is retained locally only as long as it is useful to the owner. The owner can delete stored data at any time by removing it from the local machine. The owner can revoke Hermes's access to their Google Account at any time at myaccount.google.com/permissions, after which Hermes can no longer access any Google data.
